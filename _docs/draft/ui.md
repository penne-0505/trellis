# Trellis — 画面設計書

## 1. 画面一覧

| ID | 画面名 | 種別 | MVP必須 | 主要責務 |
|----|--------|------|---------|----------|
| S1 | セットアップ | 初回のみ | 必須 | 地点設定、HC接続、パーミッション取得 |
| D1 | ホーム | 日常 | 必須 | 気分記録、テキスト入力、直近タイムライン |
| D2 | ウィジェット | 常駐 | 必須 | 気分記録のみ |
| C1 | 設定 | 随時 | 必須 | 地点変更、再接続、権限確認 |

---

## 2. 画面遷移

```
[初回起動] → S1 → D1 ↔ C1
[通常起動] → D1 ↔ C1
[ウィジェット] → D2（記録完了後はD1を開かない）
```

---

## 3. 各画面詳細

### S1. セットアップフロー
**表示条件:** 初回起動時のみ（設定完了フラグで判定）

**コンテンツ:**
1. **地点設定**: 住所入力 or 「現在位置を使用」ボタン
2. **Health Connect**: 接続許可リクエスト（標準インテント）
3. **パーミッション**: 位置情報（フォアグラウンド）の許可要求
4. **デバイス確認**: 「ウェアラブルデバイスをお持ちですか？」（いいえの場合はMVP利用不可案内）

**設計方針:** 
- ステップ数は4ステップ以内
- 各ステップで「後で」は不可（必須設定のみ）
- 完了後は自動的にD1へ遷移

### D1. ホーム画面
**レイアウト構成:**

```
┌─────────────────────────────┐
│ [設定アイコン]    [日付表示] │
├─────────────────────────────┤
│                             │
│   [😊 Good]  [😞 Bad]      │  ← 気分記録（常時表示）
│                             │
├─────────────────────────────┤
│ [テキスト入力フィールド...]  │  ← インライン入力（X/Thino風）
│ [送信ボタン]                 │
├─────────────────────────────┤
│ 直近タイムライン             │
│ • 10:30 😊 Good @渋谷        │
│ • 09:15 "朝起きられなかった"  │
│ • 08:00 😞 Bad              │
└─────────────────────────────┘
```

**インタラクション:**

**気分記録:**
- **操作手数:** 起動（0）→ タップ（1）= **合計1操作**
- タップ即座に記録（確認ダイアログなし）
- 位置情報取得は非同期（ユーザーは待たない）

**テキスト入力:**
- **操作手数:** 起動（0）→ フィールドタップ（1）→ 送信（2）= **合計2操作**
- 送信ボタンは入力有無に関わらず常時アクティブ（空文字はバリデーションで弾く）
- 送信後フィールドをクリアしキーボードを閉じる

**タイムライン:**
- 直近24時間の記録を時系列表示（気分・テキスト混在）
- タップで詳細は表示しない（MVPでは閲覧のみ）

### D2. ホームウィジェット
**サイズ:** 2x1（2セル×1セル）推奨

**表示:**
```
┌──────────┬──────────┐
│   😊    │   😞    │
│  Good   │   Bad   │
└──────────┴──────────┘
```

**動作:**
- タップ即座に記録（`source = 'widget'`）
- 位置情報取得を試行（失敗しても無視）
- トースト表示: 「記録しました」

**制約:**
- テキスト入力は提供しない
- 設定変更は不可（アプリ本体へ誘導）

### C1. 設定画面
**セクション構成:**

**データ連携:**
- 現在の気象地点（変更ボタン）
- Health Connect接続状態（再接続ボタン）

**権限:**
- 位置情報権限状態（再要求ボタン）

**アプリ情報:**
- バージョン
- オープンソースライセンス（Open-Meteo等）

---

## 4. 操作要件（共通）

**入力操作の制限:**
- すべての記録操作は**3操作以内**を必須とする
- 確認ダイアログは原則使用しない（アンドゥ機能もMVPでは不要）

**エラーハンドリング（UI側）:**
- 位置情報取得失敗: ユーザーに通知しない（裏側でnull保存）
- Health Connect未接続: ホーム画面にバナー表示「設定で接続してください」
- ネットワークエラー（気象）: 次回同期時まで保留、ユーザー通知なし

**スコープ外（将来）:**
- 過去データの編集・削除機能
- 睡眠詳細画面（ヒポグラム等の可視化）
- 統計グラフ表示
- テーマ設定
